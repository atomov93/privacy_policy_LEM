# LetsMessageEncrypt 1.4.0 — Release Notes

## English (full)

### What’s New

#### Easier to get started
- New skippable first-run tutorial walks through create/join keys, encrypt/decrypt, and fingerprint verification
- Reopen the guide anytime with the help button in the header
- Context-aware guidance under the logo tells you what to do next on Keys and Encrypt

#### Clearer interface
- App logo-led header replaces the old title block
- Clearer empty states when you have no keys yet
- Paste control on the decrypt ciphertext field

#### Accessibility
- Follows system Reduce Motion, Bold Text, and high-contrast preferences
- Safer Dynamic Type scaling on dense chrome
- Stronger screen-reader labels, modal announcements, and live regions
